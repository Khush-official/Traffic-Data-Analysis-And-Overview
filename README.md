# Traffic Data Analysis and Overview | Power BI

## About the Project

This is a Power BI project I created to analyze traffic inspection data and understand different patterns related to traffic violations, accidents, fatalities, vehicle types, and other factors.

I built an interactive dashboard where users can explore the data using filters, charts, KPI cards, and a map.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX

## What I Worked On

- Created KPI cards to show important numbers from the dataset.
- Used slicers to filter the data based on different Yes/No fields.
- Created a line chart to analyze inspection trends over time.
- Used a map to display the geographical distribution of recorded cases.
- Analyzed different violation types and vehicle categories.
- Created visualizations to explore race distribution.
- Worked on dashboard layout, formatting, and interactivity.


## What I Learned

While working on this project, I practiced data visualization, creating measures, using slicers, designing interactive reports, and presenting data in a clear and understandable way.

I also learned how different visuals can help users explore a dataset from different perspectives.
